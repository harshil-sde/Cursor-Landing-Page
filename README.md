This project is a recreation of cursor using only **HTML and CSS**

## Sections Recreated
- Top navigation bar
- Hero section with headline, description & CTA
- Trusted by / company logos
- Feature sections 
- Feature cards (grid layout)
- Testimonials
- Use cases
- Changelog
- Team 
- Final call-to-action
- Footer

## Colors Used
- Main background: `#14120b`
- Secondary background: `#1a1914`
- Accent `#e64b02`
- Text color: `#f2f1f1`
